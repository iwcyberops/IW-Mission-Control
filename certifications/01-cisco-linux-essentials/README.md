## 🧠 Core Competencies & Syllabus Validated

The examination and lab assessments for this credential evaluate mastery across the following operational domains:

```
  ┌─────────────────────────────────────────────────────────────────────────┐
  │                 LINUX ESSENTIALS CORE COMPETENCY MATRIX                 │
  └────────────────────────────────────┬────────────────────────────────────┘
                                       │
      ┌────────────────────────────────┼────────────────────────────────┐
      │                                │                                │
┌─────▼───────────────┐     ┌──────────▼──────────┐     ┌───────────────▼─────┐
│ 1. SYSTEM ARCH &    │     │ 2. DATA PIPELINES & │     │ 3. PERMISSIONS, DAC │
│    FHS DIRECTORIES  │     │    STREAM PARSING   │     │    & PROCESS MODELS │
│  (/etc, /proc, /dev)│     │  (grep, sed, awk)   │     │ (chmod, SUID, kill) │
└─────────────────────┘     └─────────────────────┘     └─────────────────────┘
```

1. **Linux Operating System Architecture:** Understanding the separation between Kernel Space and User Space, open-source licensing models, major Linux distribution families (Debian/Ubuntu, Red Hat/Fedora), and package management systems.
2. **Filesystem Hierarchy Standard (FHS):** Navigating and auditing critical directory structures including `/etc` (configurations), `/proc` and `/sys` (kernel virtual filesystems), `/dev` (device nodes), `/var/log` (telemetry), and `/tmp`.
3. **Advanced CLI Data Manipulation:** Constructing high-speed text extraction pipelines using standard UNIX filters: `grep -E`, `awk`, `sed`, `sort`, `uniq`, `cut`, and `tr`.
4. **Discretionary Access Control (DAC) & Permissions:** Mathematical calculation of `umask`, setting symbolic and octal permissions (`chmod`), managing user/group ownership (`chown`), and analyzing execution privileges on `SUID`, `SGID`, and Sticky bit binaries.
5. **Process Governance & System Signals:** Querying active system state with `ps`, `top`, `lsof`, managing process priorities (`nice`/`renice`), and transmitting standard UNIX signals (`SIGTERM`, `SIGKILL`, `SIGSEGV`).
6. **Shell Scripting Automation:** Developing modular Bash automation scripts, handling standard input/output redirection (`<`, `>`, `2>&1`), piping (`|`), and parsing CLI arguments.
