## 🧠 Core Competencies & Syllabus Validated

The curriculum and assessments for this credential evaluate mastery across the following foundational web domains:

```
  ┌─────────────────────────────────────────────────────────────────────────┐
  │                 HTML ESSENTIALS CORE COMPETENCY MATRIX                  │
  └────────────────────────────────────┬────────────────────────────────────┘
                                       │
      ┌────────────────────────────────┼────────────────────────────────┐
      │                                │                                │
┌─────▼───────────────┐     ┌──────────▼──────────┐     ┌───────────────▼─────┐
│ 1. DOM STRUCTURE &  │     │ 2. INPUT FORMS &    │     │ 3. MULTIMEDIA &     │
│    HTML5 SEMANTICS  │     │    DATA SUBMISSION  │     │    HYPERLINK TREES  │
│  (Tags, Elements)   │     │ (GET/POST, Headers) │     │ (Assets, Schemas)   │
└─────────────────────┘     └─────────────────────┘     └─────────────────────┘
```

1. **Document Object Model (DOM) Foundations:** Anatomy of HTML5 documents, doctype definitions, structural hierarchies (`<html>`, `<head>`, `<body>`), metadata tags, and character encoding standards (UTF-8).
2. **Semantic Content Architecture:** Implementing semantic tags (`<header>`, `<nav>`, `<article>`, `<section>`, `<footer>`) to construct accessible, logically compartmentalized web pages.
3. **Form Elements & Data Transmission:** Engineering user input interfaces (`<form>`, `<input>`, `<select>`, `<textarea>`), analyzing HTTP form submission methods (`GET` vs. `POST`), input attributes, and client-side validation constraints.
4. **Hyperlinks & Resource Navigation:** Deep linking structures, relative vs. absolute URI paths, target attributes, and resource routing.
5. **Tables & Structured Data Presentation:** Designing complex data tables (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<td>`, `<th>`), handling row/column spans, and tabular data structuring.
6. **Multimedia Integration & Asset Optimization:** Embedding native media elements (`<img>`, `<audio>`, `<video>`, `<figure>`), managing asset paths, and configuring responsive media attributes.
