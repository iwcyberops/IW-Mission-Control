## 📅 The 42-Month Master Plan (5 High-Level Phases)

This mission is structured into 5 brutally comprehensive phases, designed for absolute depth and intellectual rigor:

1. **[Phase 01: Foundations & Systems Architecture](./roadmap/phase-01-foundations-architecture/)** `(Months 01–08)`
   * Linux Internals, Network Protocols, Python Automation, OS Internals, Applied Crypto, Systems C Programming.
2. **[Phase 02: Offensive Security & Exploitation](./roadmap/phase-02-offensive-sec-exploitation/)** `(Months 09–18)`
   * Windows Internals, Active Directory, Reverse Engineering, Binary Exploitation (ROP/SROP), C++ UAF, Mobile/Cloud Security.
3. **[Phase 03: Hardware, Firmware & Fuzzing](./roadmap/phase-03-hardware-firmware-fuzzing/)** `(Months 19–27)`
   * Digital Logic, Hardware Buses (SPI/UART/I2C), Firmware Emulation, Hypervisors, Fuzzing (AFL++/LibFuzzer), Heap Exploitation.
4. **[Phase 04: Deep Vulnerability Research](./roadmap/phase-04-deep-vulnerability-research/)** `(Months 28–35)`
   * Snapshot Fuzzing, SMT Solving (Z3/angr), Concurrency Races, CodeQL Variant Analysis, Microarchitectural Side-Channels.
5. **[Phase 05: Advanced Specialization & 0-Day Research](./roadmap/phase-05-specialization-independent-research/)** `(Months 36–42)`
   * Source Tree Audits, Custom Fuzzer Engineering, Target Patch Diffing, and the Independent 0-Day Defense Capstone.

## ⚙️ The Operational Engine

Success in this roadmap is governed by the **60/30/10 Rule** over a 12-Hour daily focus cycle:
* **60% (7.2h)** - Hands-on implementation, coding, reverse engineering, and exploit development.
* **30% (3.6h)** - Deep theoretical ingestion (RFCs, Intel SDM, Kernel Source).
* **10% (1.2h)** - Documentation, architectural mapping, and Git repository maintenance.
